# スモークテスト手順（実機確認）

ユニットテスト（`npm test`）は純粋関数のみ。VS Code API 依存部分はここを手で潰す。
`F5`（Extension Development Host）か、インストール済み版（reload 後）で実施。

## 0. 起動
- [ ] アクティビティバーに 🦝（ponpoko-review）アイコンが出る。**黒い四角でなく**ラクーンの線画
- [ ] 開くと worktree ノードが出て `current: <branch> → target: main` が表示される

## 1. 差分ツリー
- [ ] ファイルを変更/追加/削除して 更新(↻) → A/M/D が色付き文字アイコンで出る
- [ ] 未コミットの編集・**未追跡ファイル(??)** も出る
- [ ] 表示モード切替ボタンで list ⇄ tree が切り替わる。tree で `src/handlers` 等が畳まれる

## 2. diff & コメント
- [ ] ファイルをクリック → 左=base / 右=作業ツリー の diff が開く
- [ ] 右側の行で **複数行を選択** → ＋ → コメント追加。md 見出しが `path:開始-終了` になる
- [ ] コメントが **右(作業ファイル)側** に付く（行番号がズレない）

## 3. Viewed チェック
- [ ] ファイルのチェックボックスON → グレー淡色化。チェック時から内容を変えて保存 → 自動でチェックが外れる
- [ ] tree でフォルダをチェック → 配下が一括チェック。配下全ONでフォルダも自動ON
- [ ] チェック押下で **ちらつかない**（git再取得が走らない）
- [ ] worktree 配下を全部チェック → worktree 行が `✓ N 件 完了` ＋アイコン緑、tooltip に「✓ すべて表示済み」。1 つ外すと `✓N/M` ＋通常色に戻る

## 4. コメント操作
- [ ] コメントの ✎ 編集 → 保存/キャンセル
- [ ] 🗑 削除（スレッドが空なら消える）
- [ ] スレッドの Resolve トグル
- [ ] ファイルを展開するとコメント本文が子ノードで出る。クリックで該当行へジャンプ
- [ ] コメント表示トグル（コメントマーク）で子ノードの展開ON/OFF。💬 件数は常時出る
- [ ] コメント絞り込み($(filter))でコメントのあるファイルだけになる
- [ ] 「差分なしの worktree を隠す」($(folder)) ON → 差分の無い worktree(main 等)がトップから消え、コメント付きファイルを持つ worktree は残る。全部消えると「差分のある worktree はありません」。OFF で戻る

### 4b. ファイル全体へのコメント
- [ ] **差分の無いファイル**をエクスプローラーで右クリック → 「このファイルにコメント（ファイル全体）」→ prefix を選んで確定 → ツリーにそのファイルが 💬 アイコン（チェックボックス無し）で現れ、子ノードが「ファイル全体」
- [ ] エディタで行を選ばずにファイルコメント（Comments API）を付けても同じ扱いになる
- [ ] 差分のあるファイルでは、ファイルコメントが行コメントより先に並ぶ
- [ ] Submit → 見出しが `## path (base...HEAD)`（行番号・コードフェンス無し）で、同一ファイルの行コメントより先に出る
- [ ] Reload Window 後も復元され、Resolve / 削除で消える

## 5. 出力
- [ ] 上部 Submit → `.ponpoko-review/review.md`（全worktree統合）が**自動で開く**
- [ ] worktree 行の Submit → `.ponpoko-review/<worktree名>/review.md`（個別）
- [ ] 書き出した md の見出し直下に `書き出し: YYYY-MM-DD HH:MM:SS / base: main...HEAD` が入り、`review.md` と `review-<timestamp>.md` で同じ日時
- [ ] worktree 行の $(go-to-file) → その worktree の `review.md` が開く（無ければ統合 `review.md`、それも無ければ出力先ディレクトリをエクスプローラーで表示、ディレクトリも無ければトースト）
- [ ] ステータスバーに未提出コメント数。クリックでコメント一覧へ

## 6. 設定 / worktree
- [ ] 歯車(右端) → 出力先 / 既定の比較先 を設定できる
- [ ] worktree 行の $(git-branch) で個別比較先を設定 → ★ が付く。「グローバルに従う」で解除
- [ ] 2つ目の worktree を作って（別ブランチ）両方が並ぶことを確認

## 既知の注意
- viewHash 形式変更により、アップグレード後の初回更新で **既存 Viewed は一度だけリセット**される
- コメントは workspaceState 永続化（このマシンのこのワークスペース内のみ）
